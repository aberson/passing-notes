Passing Notes — proposal

A coordinator gets one read-only sweep that lists everything needing tidying, each row ending in an action word. It also gets a written duty to run that sweep at fixed points, your standing authority (D2-D5) to act on the safe rows, a tool that closes finished lane-open Claude windows, a written route for idle lanes that have no window, and a coordinator-handover skill that moves the coordinator seat between windows, Claude or Codex, either way.

Why this shape

One owner for coordinator hygiene, not another repair lane.

  • The sweep reuses status. Scope, refusals, and the existing coordinator attention data cannot drift, because --sweep is an additive key on the same read.
  • Process identity stays in one place. The CLI reads files only. The close helper alone proves a window is safe, and lane-status merges its rows into safe-close or operator-close.
  • Your answers become standing authority once. The sweep therefore never stops to ask. Anything not covered goes to you in one table.
  • The handover skill composes, not copies. It calls the four lane skills, and a docs test forbids its own close or launch commands.
